# BLUP — обновлённый проект

## Что изменено
- Рыночные котировки USDT/RUB и TON/RUB загружаются с CoinGecko через `/api/rates`, обновляются раз в минуту и кэшируются сервером. Котировки ориентировочные, не являются обещанием цены выплаты.
- Обновлён визуальный стиль: зелёно-бирюзовые акценты, блок курса, адаптивные элементы.
- Регистрация требует ник 3–24 символа и пароль от 8 символов; пароль хранится только в виде bcrypt-хеша. Сессия обновляется после входа.
- История показывает количество актива, статус и время. Пользователь видит только свои заявки, администратор — последние 200 заявок.
- Добавлена проверка входа перед созданием заявки.
- Убрана отправка паролей пользователей в Telegram. Telegram-уведомления о заявках включаются переменными окружения.

## Локальный запуск (Windows)
1. Установите Node.js 20 или новее.
2. Распакуйте архив и откройте папку `criptoyyyyyyy-main`.
3. Откройте терминал в этой папке и выполните `npm install`.
4. Задайте секреты в PowerShell (желательно заменить значения своими):
   ```powershell
   $env:ADMIN_PASSWORD="ваш-новый-длинный-пароль-админа"
   $env:SESSION_SECRET="случайная-длинная-строка-для-сессий"
   npm start
   ```
5. Откройте http://localhost:3000. База `data.db` создаётся автоматически рядом с `server.js`.

## Админ-панель
1. На сайте быстро нажмите 10 раз на маленький круглый логотип-пузырь в шапке. Если сайт остановлен, можно нажать на пузырь в левом верхнем углу экрана блокировки.
2. Введите значение `ADMIN_PASSWORD`, заданное при запуске.
3. В панели можно остановить/возобновить приём заявок и обновить историю последних заявок.

Если `ADMIN_PASSWORD` не задан, для совместимости используется старый пароль `fosfor322322`. Рекомендуется сразу задать собственный пароль через переменную окружения.

## Деплой на Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: `ADMIN_PASSWORD` и `SESSION_SECRET` (обязательно установите свои значения). Для Telegram-уведомлений дополнительно `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_ID`.
- Для сохранения SQLite-базы между перезапусками нужен постоянный диск и размещение `data.db` на нём. Без постоянного диска локальная SQLite-база может сбрасываться при новом деплое/пересоздании инстанса.

## Важно по котировкам
TON показывается по рыночным данным CoinGecko. Если под названием GRAM подразумевается отдельный токен, не отправляйте его по адресу TON и не используйте курс TON для расчётов — сначала уточните точный актив и сеть. Перед переводом проверяйте адрес, сеть, комиссии и окончательную сумму выплаты.
